# 💰 Expense Tracker System

A web-based Expense Tracker application built using Java technologies to help users manage their daily expenses efficiently. The system provides secure authentication, category-based expense tracking, and a user-friendly dashboard for financial insights.

---

## 🚀 Features

- 🔐 User Registration & Login (Session Management)
- ➕ Add, Edit, Delete Expenses (CRUD Operations)
- 📊 Category-based Expense Tracking
- 📈 Dashboard with Total Expense Calculation
- 👤 Multi-user Support (Each user sees their own data)
- 🏗️ MVC Architecture for scalability and maintainability

---

## 🛠️ Tech Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Java Servlets
- JDBC

**Server:**
- Apache Tomcat

**Database:**
- PostgreSQL
